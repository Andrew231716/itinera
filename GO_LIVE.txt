==================

Progetto Google Cloud già indicato: itinera-509522

abilitare billing o attivare abbonamenti. Serve il tuo login Console.

- Demo attiva finché le chiavi restano vuote

## Azioni umane residue (3–5 click) — da Maps home del progetto

Prerequisito una tantum (se non già fatto): billing attivo + abilita
Maps JavaScript API, Places API (New), Routes API.

Poi, dalla home Maps del progetto itinera-509522:

1. Menu sinistro → "Keys & Credentials" (o Credenziali)
2. "+ Create credentials" → "API key" → copia → rinomina "Itinera server"
   → Application restrictions: None (o IP) → API restrictions: Places API (New) + Routes API → Save
   → incolla in GOOGLE_MAPS_API_KEY in .env.local
3. Di nuovo "+ Create credentials" → "API key" → copia → rinomina "Itinera browser"
   → Application restrictions: HTTP referrers → aggiungi http://localhost:3000/* (e il tuo dominio)
   → API restrictions: Maps JavaScript API → Save
   → incolla in NEXT_PUBLIC_GOOGLE_MAPS_BROWSER_KEY in .env.local
4. Riavvia: npm run dev
5. Tab "Live" → "Verifica connettività" → testa Milano → Roma

Minimo click dopo APIs/billing già ok: 2× Create API key + 2× Save restrizioni + incolla in .env.local.
