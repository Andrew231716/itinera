3. COSA È STATO IMPLEMENTATO
--------------------------------------------------------------------------------

A) Preferenze stradali
- Pannello con toggle esistenti preservati
- Stati per preferenza: engine_direct | preferential | post_verified |
  unsupported | unverifiable
- Documentazione UI: non si dichiara “rispettata” senza evidenza
- Tunnel / panoramiche = unsupported; maxExtraMinutes = post-filtro

B) Esclusioni
- Edit hard/soft, raggio (punto), buffer (segmento)
- Validazione poligono (≥3 punti distinti, area non nulla)
- Densificazione polyline per ridurre falsi negativi
- Punti sul bordo poligono trattati come inside (conservativo)
- Conformità: true solo se nessuna violazione hard e nessun hard non verificabile
- UI: badge vincolo violato / non verificabile / conforme

C) Motore di routing estensibile
- Interfaccia RoutingEngine comune
- GoogleRoutesEngine: operativo con GOOGLE_MAPS_API_KEY
- OpenRouteServiceEngine: adapter predisposto; NON inventa percorsi
- Selezione via ROUTING_ENGINE (default google_routes)
- Valutazione documentata ORS / GraphHopper / OSRM in README

D) Condivisione Google Maps
- Preview riepilogo prima dell’apertura
- Conferma esplicita (esclusioni non trasferite)
- Native Web Share API con fallback copia
- Segmentazione etichettata se >8 waypoint (nessuna tappa eliminata in silenzio)
- Link pubblico locale + cloud (token)

E) Supabase
- Schema SQL: trips + shared_trips + RLS + RPC get_shared_trip
  → supabase/migrations/001_itinera_trips.sql
- Client anon only (mai service role in NEXT_PUBLIC_*)
- HybridTripRepository: localStorage sempre; sync best-effort se configurato
- Pagina /share/[token] + API GET /api/share/[token]
- Senza Supabase: locale continua a funzionare

F) Assistente OpenAI
- Structured Outputs (json_schema strict) + validazione Zod
- Località risolte SOLO via Places API (mai coordinate inventate)
- Flusso: interpreta → preview → conferma utente → aggiorna store → calcola
- Annullamento preview supportato
- Senza OPENAI_API_KEY: status unavailable, messaggio chiaro

G) UX / stati
- StatusBanner: demo, live, calcolo, nessun percorso, vincolo violato,
  non verificabile, errore
- Brand preservato (Itinera, teal #2C5F7C, oro #D4A017, Fraunces/Manrope)

H) Test
- Vitest: 15 test, tutti pass
- geometria/vincoli, maps links, preferenze, demo routing, schema assistant,
  repository locale
- Nessuna chiamata a servizi a pagamento nei test

I) Documentazione
- README.md aggiornato (IT)
- .env.example aggiornato
- LIMITAZIONI.txt
- Tabella funzionalità operative vs config-required

7. LIMITAZIONI RESIDUE (PRIORITÀ CORRETTEZZA)
--------------------------------------------------------------------------------
1. Senza chiave Google: demo onesta, routes=[] — nessun path inventato.
2. Google non forza avoid-area nativi: post-check geometrico (possibili
   falsi negativi su zone strettissime).
3. Tunnel/scenic non applicati dal motore.
4. Link Maps non trasferisce esclusioni custom.
5. ORS non attivo end-to-end.
6. Supabase richiede migration manuale + env.
7. Nessuna UI login: sync cloud autenticato dipende da sessione Supabase.
8. Assistente inutilizzabile senza OPENAI_API_KEY.
9. Nessun remote Git in questo VM.
